# 単位表記変換（実験）

`experimental.text-unit-notation@1` / `TextUnitNotation`。管理Issue #34 の仕様案に基づく実験実装。正式採用・標準同梱は未決定で、この実装をもって昇格しない。

- 入力 `in` / 出力 `out`: ja / Text。文中の「数値+単位記号」を日本語の単位名へ置き換える。
- 設定はなし（空オブジェクト `{}` のみ有効）。未知キーは invalid-config。
- 数値文法: 半角数字のみ。桁区切りカンマ（3桁組）と小数部を含む。数値部分は原文のまま保持する。符号・全角数字は対象外。
- 数値と単位の間の空白は最大1つまでを許容し、出力では空白を付けない（10 kg → 10キログラム）。
- 単位表は固定・明示する（長さ・質量・体積・時間・速さ・面積・圧力・エネルギー・情報量など約45件。README末尾ではなく実装の表が正）。大小文字は区別し、表にない綴り（Kg 等）は変換しない。最長一致を採る（mm 優先、m 単独も可）。
- 単位の直後が英数字の場合は単語の一部とみなして変換しない（10 kg2 や 10 meters は対象外）。未知単位・単位なし数値はそのまま保持する。
- 単位の量的換算（1km→1000m 等）と文脈推測はしない。℃ は「度」とする。
- Packet検証後に処理する。NoOutputはNoOutput、空文字はData。変換が起きなかった場合は入力そのままで Packet/meta を保持し、変わった時は入力metaを省略する。入力欠落はmissing-input、Text以外はinvalid-root。入力を変更しない。

検査: `cargo test --locked --all-features --test nodes_text_unit_notation`。正式fixtureを弱めず、このディレクトリーの契約例を実装に照合する。実Wasm検証とWindows CIの結果はPR側で確認する。

戻し方: 対象PRをrevertする。実験kindを使用したグラフは、別ノードへ交換してから実装を除去する。
