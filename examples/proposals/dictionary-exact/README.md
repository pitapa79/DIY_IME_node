# 完全一致辞書の提案例

状態: **未採用・未実装の仕様検討用データ**。[辞書ノード仕様案](../../../docs/dictionary-node-proposal-v0.1.md)を読むための固定データであり、現行ノードが読める辞書やCLI実行用グラフではない。

- [entries.tsv](entries.tsv): この提案用に作ったテスト辞書。ヘッダーはreading / surface / weight。実際の区切りはタブ。外部辞書のダウンロード・転載・同梱は行っていない。
- [cases.json](cases.json): このTSVに対する完全一致検索、未知語、空文字、Unicode、NoOutput、不正rootの期待値案。正式なNode設定や契約ファイルではない。

こうすいの候補は「降水90・香水30・洪水90」の行順。検索ではこの順序を維持し、候補選択ノードが最大スコアを選ぶと同点先頭の「降水」になる想定。

`が` は1コードポイントの辞書キー。ケースの `か\u3099` は2コードポイントで、正規化しない提案のため未知語になる。未知語候補はscoreを省略し、空入力もDataの空Textを1候補返す。

JSONの `proposal`、`dictionary`、`input`、`expected` は提案例を説明するためのキー。辞書をロードするNode API・ホスト設定・エラーコードの正式採用を表さない。JSONを読み込んで構造を確認しても、辞書処理の動作検査にはならない。
